# 知题

知题是一款完全离线的 Android 刷题应用，适合将个人 XLSX 题库整理成可长期使用的学习项目。题库、学习进度、错题、收藏、备注、统计与学习记录均保存在本机，无需网络权限，不对外传输任何数据。

## 主要功能

- 从 XLSX 导入单选题、多选题、判断题、填空题和案例题
- 将一个或多个 XLSX 题库自由组合成多个刷题项目
- 提供顺序刷题、随机刷题和随机组卷三种模式
- XLSX 导入时可按题型选择，已导入题库也可重新启用或停用题型
- 支持全部题目或历史错题范围刷题
- 保存顺序刷题与随机刷题的本轮进度，退出后可以继续
- 记录当前错题、收藏、备注、做题次数、错误次数和正确率
- 支持当前错题、收藏题目、备注题目的单题重刷和完整重刷
- 按题目查看学习明细，并按初始顺序、做题次数、错误次数或正确率排序
- 生成分题型刷题综述，保存可筛选、查看和清除的学习记录
- 支持完整数据备份与恢复

## 快速开始

- 在“题库”页面选择 XLSX 文件并导入。
- 在“学习”页面新建项目，选择需要加入项目的题库。
- 项目说明可以留空，未填写时项目卡片不会显示说明文字；长按项目卡片后，卡片会跟随手指移动，在新的项目间隙停留 0.5 秒即可通过动画平滑插入，松手后自动保存排序。
- 打开项目，选择全部题目或历史错题，再选择刷题模式。
- 在“统计”页面查看学习概况、学习明细、当前错题、收藏和备注题目。
- 在“历史”页面查看以往练习的刷题综述。
- 在“设置”页面管理案例题显示方式、备份恢复、使用说明和关于信息。

## XLSX 题库格式

工作表第一行必须是表头，表头顺序不限。应用会按表头名称读取每行数据。

必需表头：

- `题型`：单选题、多选题、判断题、填空题或案例题
- `题干`：题目正文；案例题中也用于案例材料和小题题干
- `答案`：正确答案

可选表头：

- `出自规范`：题目解析、依据或来源
- `A` 至 `I`：选项 A 至选项 I

普通单选题、多选题、判断题和填空题每行对应一道题。空白选项不会显示。填空题只需要“题型”“题干”和“答案”三列，不需要 A 至 I 选项。

### 答案写法

- 单选题可填写 `A`。
- 多选题既可填写 `A,B,C`、`A，B，C`，也可填写 `ABC`；导入时会自动规范化。
- 判断题支持用选项字母或常见的正确、错误表述填写答案。
- 判断题没有选项时，应用会自动补充 `A=正确`、`B=错误`，不会因此显示导入警告。
- 填空题答案按文本保存。答题时输入内容必须与 XLSX 中的答案完全匹配，包括大小写、空格和标点，才会判定正确。但填空题答案中的标点符号不区分中英文。
- 答案可在答题结束后通过“修正答案”按钮进行修正，修正后的答案将持久化保存。

### 案例题规则

案例题根据“答案”列判断材料行和小题行：

- 答案为空的行，其“题干”内容作为案例材料。
- 答案不为空的行，其“题干”内容作为案例小题。
- 两个答案为空的案例材料行之间，组成一道完整案例题。
- 案例小题答案只有一个选项时按单选作答，包含多个选项时按多选作答。

“设置”中的“案例题题目是否拆分”默认为开启。开启时，每个案例小题作为独立刷题单元显示；关闭时，同一案例下的小题合并显示并一次性提交。该设置只改变显示和作答形式，不会把一整套案例错误统计成一道小题。

## 题库、项目与全局学习状态

题目内容属于导入的 XLSX 题库，一个题库可以加入多个刷题项目，一个项目也可以组合多个题库。删除项目不会删除原题库，也不会删除其他项目。

同一道导入题目在不同项目中的以下数据全局共享：

- 当前错题状态
- 收藏状态
- 题目备注
- 答题次数与错误次数
- 总正确率

项目自己的题库组合、顺序进度和随机进度独立保存。项目页会显示已经学习、累计做题、当前错题和正确率。

## 刷题模式

### 顺序刷题

按照题库原始顺序学习。应用保存当前轮次进度，下次进入时从上次位置继续。提交本轮最后一题后，“下一题”按钮会变为“完成本轮”，点击后进入刷题综述，不会重新跳回第一题。点击“重刷”可在确认后从第一题重新开始，并重置本次计时。

### 随机刷题

在完整刷完当前题目范围之前不重复抽题。应用保存本轮随机顺序和进度，下次进入时可以继续。完成本轮最后一题后进入刷题综述；点击“重刷”会重新随机排列并从第一题开始，同时重置本次计时。

### 随机组卷

在独立的组卷设置页面按题型设置抽题数量、分数比值和限时。各题型比值会按选中的题型归一到 100 分，再按该题型题量分摊到每道题；综述大圆圈显示总得分，分题型综述显示正确率和所得分。试题按单选、多选、判断、填空、案例的顺序分组排列。答题时可预览题号和当前完成情况，时间到会自动交卷。未交卷退出时会确认，重新进入时可以继续上一次组卷。

设置页的“随机不打乱选项”默认开启，且只影响随机刷题和随机组卷。关闭后会打乱单选题、多选题的选项内容，左侧选项标识仍按 A、B、C、D 等顺序显示；其他刷题模式始终保持题库中的原始选项顺序。

### 专项重练与单题练习

统计页中的错题、收藏和备注均可开始整组重练，也可以点击题目卡片进行单题练习。整组重练会保存未完成进度，下次开始同类重练时可以选择恢复；最后一题提交后，通过返回、保存退出或 Android 系统返回都会进入刷题综述。单题练习提交答案后会立即保存为一条学习记录。两种入口都会在进度条右侧显示本次练习计时。

## 答题、解析与备注

- 单选题和判断题选择一个答案，多选题可以选择多个答案，填空题通过文本框输入答案。
- 提交后会显示自己的答案、正确答案和题目解析；正确内容为绿色，错误内容为红色。
- 解析页支持收藏题目，并可复制案例、题干和答案。
- 每道题解析下方都有一个自动保存的备注框，可记录易错点、记忆方法或补充说明。
- 统计页的题目清单包含错题、收藏和备注三类，支持批量重练和单题练习。
- 从学习明细卡片可以直接查看单题解析。

## 刷题综述

完成练习或在顺序、随机模式中保存退出后，应用会生成本次练习综述。综述显示正确、错误、未答、总用时，以及各题型的正确率和用时。

题号圆圈用颜色区分作答结果。点击题号可打开该题解析，并可左右滑动查看上一题或下一题。“查看错题”只会打开本次练习中的错题解析。

## 统计与学习历史

“统计”页面显示：

- 已经学习：至少答过一次的题目数量
- 累计做题：所有题目的总答题次数
- 练习总次数：累计保存过的练习次数，不因清除历史显示记录而减少
- 正确率：全部答题记录的总体正确率

项目中的学习概况按单选题、多选题、判断题和填空题分别显示，没有题目的类别不会显示对应卡片。点击某一题型卡片，只查看该题型的学习明细，页面标题会显示“项目名 · 题型明细”；点击“查看题目明细”则查看项目中的全部题目。

学习明细可按初始顺序、做题次数、错误次数和总正确率进行正序或倒序排列。

“历史”页面保存学习记录卡片，包括刷题项目、题目数量、正确率、刷题时间、刷题用时和刷题模式。支持按近 3 天、近 5 天等时间范围、刷题项目和刷题模式筛选。点击卡片可重新查看当次刷题综述；左滑卡片可清除单条记录，也可清除当前筛选结果。删除项目后，与该项目关联的学习记录不再显示。

清除学习历史只影响历史页面中的可见记录，不会回退已经累计的题目学习统计、练习总次数等数据。

## 本地数据与备份

Android 版本使用 SQLite 保存题库与学习数据。浏览器开发环境使用 localStorage 作为轻量调试后端。

设置页面可以导出完整 JSON 备份，并从备份文件恢复。备份包含题库、项目、学习状态、收藏、备注、进度和历史记录。导入 XLSX 或恢复备份时会显示加载状态，请等待操作完成后再离开页面。

重要数据建议定期备份。卸载应用或清除应用数据前，请先把备份文件保存到安全位置。

## 技术架构

- Vue 3、TypeScript、Vite
- Ionic Vue、Vue Router、Pinia
- Capacitor 8
- `@capacitor-community/sqlite`
- SheetJS `xlsx`
- Vitest
- Android Gradle Plugin 8.13
- Android compileSdk 36、targetSdk 36、minSdk 24

应用采用题目内容、项目关系和全局学习状态分离的数据结构。题目以导入来源为基础保存，项目只引用题库；答题记录、收藏、错题与备注按题目全局维护。
